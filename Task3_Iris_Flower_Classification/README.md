# CodSoft Task 3 - Iris Flower Classification

## Internship
Data Science Internship - CodSoft

## Task
Iris Flower Classification

## Objective
To develop a Machine Learning classification model that classifies
Iris flowers into different species based on their sepal and petal
measurements.

## Dataset
Iris Flower Dataset containing:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Model Used
Logistic Regression

## Result
Test Accuracy: 97%

## Classes
- Iris-setosa
- Iris-versicolor
- Iris-virginica

- Pandas
